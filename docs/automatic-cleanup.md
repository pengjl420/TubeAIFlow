# TubeAiFolw 自动清理

入口：系统设置 → 基础与存储 → 自动清理。默认关闭，保留 30 天，每天本机时间 03:00 执行。保留天数支持 1–3650 天，保存设置后无需重启调度器。

启用后永久删除以下历史文件，不进入回收站：

- 工作目录 `logs/engine.log.N`：按最后修改时间清理轮转日志，保留当前运行日志和服务标准输出日志。
- 已完成独立配音任务目录中的 `logs/tts*.log` 和 `logs/error*.log`：按最后修改时间清理，保留 JSON 进度、结果文件。
- 可选「同时删除过期的已完成配音任务和音频」：按任务完成时间清理整个受管任务目录及数据库任务记录。清理前请导出需要长期保留的音频到其他目录。

排队、运行、暂停和失败任务不自动删除；视频项目、音色、模型、凭据、数据库、项目素材、ComfyUI 输出不在本次自动清理范围内。未知目录及没有完成时间的任务不会按任务过期清理。

调度器随本地引擎运行，每分钟检查一次。应用关闭时不执行；下次启动补执行最近一次错过的计划。执行日期和数量写入工作目录 `.runtime/cleanup-state.json`，摘要及错误写入引擎日志。重启不会重复执行已记录日期。文件占用、权限等导致删除失败时保留任务记录，下次每日清理继续尝试。

清理使用配音队列状态锁，重新检查任务状态和进程是否停止；删除前验证受管目录边界，拒绝符号链接和 Windows 目录联接。不要将受管工作目录配置为链接目录。

这些设置存储在现有系统设置 JSON 中，无数据库表结构变更。升级后自动填充默认值，不会自动开启或删除已有用户数据。
